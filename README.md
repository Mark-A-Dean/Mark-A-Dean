## Powershell champion

The bottom line is that PowerShell modules are easily distributed and file copied, especially in a Microsoft environment. Using modules has proven an efficient alternative to software packagers and installers. Additionally, PowerShell became platform independent when PowerShell Core was released.

PowerShell can be learned quickly. PowerShell leans heavily on .NET, which brings C# into clearer focus for the learner. I consider PowerShell to be a polyglot. PowerShell executes from SQL Server jobs either from SSIS packages or standalone; and it readily interprets or parses other languages—especially markup languages. However, PowerShell users typically start with more basic functional programming to build familiarity. For example, I began by running _Get_-type cmdlets against **Active Directory**. Soon, I began to build custom classes and functions when special projects began to come my way. Along the way, SQL Server was pressed into service, and I found building classes, cmdlets, types, and modules accelerated capabilities.
